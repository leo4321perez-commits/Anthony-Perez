# CLI App

**The project brief is in [PROJECT.md](./PROJECT.md).** Start there.

I created in this project a classic rock paper scissor game that you can play anywhere. The way it works is by receiving the user choice of Rock,Paper,Scissors and the computer does a move as well on its own by importing pythons built in function random. 
1.press play 
2.insert name
3.choose from options [ Rock, Paper , scissors]
4. see who won
5.To Exit type Exit
